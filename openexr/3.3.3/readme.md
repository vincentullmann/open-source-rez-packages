This will download, build, and create a [rez](http://nerdvegas.github.io/rez/) package for [openexr](https://github.com/AcademySoftwareFoundation/openexr) 3.3.3 on linux.  

Tested on RedHat 3.10.0-693.11.1.el7.x86_64

## Building

 1. Run `setup.sh`
 2. Set the package installation options in build.sh
 3. Run `build.sh`
 4. Test via `rez-env openexr-3.3.3`
